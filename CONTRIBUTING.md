# Contributing

Pane's source code is not public, but there are many ways to help.

## Report a bug

[Open a bug report](../../issues/new?template=bug_report.yml) and include:

- Pane version (Pane › About Pane, with Settings open), Mac model and macOS version;
- the displays involved and how they are connected (USB-C, HDMI, DisplayPort,
  DisplayLink dock, adapter brand);
- what you did, what you expected and what happened;
- if useful, the output of `pane debug` and the last lines of `pane log`.

If a change left you without a picture: wait — Pane reverts risky changes by itself —
or press ⌃⌥⌘Z, or use Panel › Tools › Restore.

## Suggest a feature

[Open a feature request](../../issues/new?template=feature_request.yml). Tell us the
problem you want solved, not only the solution: it helps find the best design.

## Help with hardware

Some features are written but couldn't be tested on real hardware yet: HDMI-CEC, network
TVs and receivers, EDID writing, Novastar processors. If you own one, a short report
("works" / "doesn't work, here is the log") is extremely valuable.

## Translations

Pane is available in 11 languages. If a text is wrong, unclear or cut off in your
language, open an issue with a screenshot and the correct wording.
